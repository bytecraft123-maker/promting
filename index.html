Module 01 10 min read

Introduction to Prompt Engineering

A language model produces a continuation of the information it receives. Prompt engineering is the practice of making that continuation useful, relevant, and reliable.

The Central Question & Core Concept

Imagine giving a language model the opening words: "The most important discovery of the experiment was…" Many continuation types are possible. The model could complete a technical lab report, write a science-fiction novel, or synthesize a brief executive summary. The surrounding prompt determines which trajectory is activated.

Prompt engineering goes far beyond clever phrasing. In modern application pipelines, it encompasses context retrieval, conversation state management, output constraint enforcement, and downstream validation.

Vague vs. Designed Prompt 
# Bad Prompt:
"Explain transformers."

# High-Performance Designed Prompt:
"Explain the Transformer neural architecture to 1st-year Computer Science students.
- Start with the core bottleneck of classical seq2seq models.
- Introduce attention as a context-weighting mechanism.
- Include 1 comparative Markdown table and keep length under 300 words.
- Define technical terms before first use."
Historical Context

Seq2Seq & Attention Bottlenecks

Early RNN/LSTM seq2seq encoders squeezed long sentences into a single fixed-size thought vector. Attention revolutionized NLP by allowing decoders to dynamically consult all input representations with varying weights at each generation step.

What Does GPT Stand For?

Generative: Produces novel token sequences autoregressively.
Pre-trained: Learns general structural knowledge over billions of parameters.
Transformer: Leverages multi-head self-attention without recurrent limitations.

Module 02 17 min read

Understanding How Language Models Work

#

Tokenization

LLMs don't read words—they map text fragments into Token IDs. Subword tokenization impacts context budget, pricing, character-level tasks, and multilinguality.

🌡️

Temperature & Softmax

Logits are normalized into probabilities. Temperature scales distribution sharpness: 0.0 turns generation deterministic/greedy, while 1.0+ expands variety.

⚠️

Hallucinations

Fluent text carries no inherent guarantee of factual truth. Hallucinations range from fabricated API parameters to plausible-looking yet non-existent citations.

Temperature Heuristics Guide

Setting Use Case Behavior & Trade-offs
0.0 - 0.3 Factual extraction, math, code formatting High stability, repetitive phrasing, lower hallucination risk.
0.5 - 0.8 General writing, summaries, Q&A chat Natural tone variation with balanced coherence.
0.9 - 1.3 Brainstorming, storytelling, poetry High creative range, elevated risk of incoherence.

Chat Models, Human Feedback & Tools

The Alignment Pipeline (HHH Framework)

Base LLMs predict continuous text. To transform them into aligned conversational assistants that are Helpful, Honest, and Harmless, models undergo a multi-stage post-training pipeline:

1. Base Training

Massive unsupervised next-token pretraining on web corpora.

2. SFT

Supervised Fine-Tuning on thousands of curated Q&A dialogue turns.

3. Reward Model

Trained on pairwise human preference rankings of outputs.

4. RLHF / DPO

PPO/DPO optimization aligning outputs to maximize human preference scores.

Structured Message Roles in Dialogue

System Role

Defines global directives, behavioral rules, constraints, and safety limits.

User Role

Contains specific queries, dynamic input texts, or attached task documents.

Assistant / Tool

Model outputs and external tool execution responses fed back into context.

Module 05 22 min read

Prompt Content & RAG Architecture

Lexical vs Neural Retrieval

Lexical (BM25 / Jaccard): Matches exact keywords and error codes quickly.
Neural Embeddings (Cosine Similarity): Projects text chunks into dense vector spaces to match semantic meanings across paraphrases.

Chunking & Snippetizing

Dividing long documents using fixed sliding windows with overlap (e.g., 200 words with 80-word stride) preserves context continuity across section boundaries.
