Chapter 01

Introduction to Prompt Engineering

Big idea: A language model produces a continuation of the information it receives. Prompt engineering is the practice of making that continuation useful, relevant, and reliable.

The Central Question

Imagine giving a language model the words: "The most important discovery of the experiment was…" The words surrounding the request determine which kind of continuation is likely.

Evolution of Models

  • 1940s onward: Statistical language models and Markov approaches.
  • 2014: Sequence-to-sequence (seq2seq) models with encoders and decoders.
  • 2017: The Transformer architecture introducing attention mechanisms.
  • 2018–Present: GPT (Generative Pre-trained Transformer) models enabling context-sensitive prompting.

Anatomy of a Well-Designed Prompt

  1. States the target audience.
  2. Supplies scope and sequence.
  3. Specifies presentation format.
  4. Sets constraints on length and terminology.
Chapter 02

Understanding How Language Models Work

Big idea: To use a language model well, understand what it actually processes: tokens, probability distributions, and context.

Tokens & Context Windows

Models operate on token IDs rather than raw words. Formatting, punctuation, and language choice directly impact token counts and context budgets.

Autoregression & Temperature

Generation happens one token at a time based on probability scores (logits converted via softmax). Temperature controls distribution sharpness:

  • Low Temperature (0.0–0.3): Predictable and factual outputs.
  • Medium Temperature (0.5–0.8): Balanced variation in writing.
  • High Temperature (0.9+): Creative variation with higher risk of instability.

Hallucinations

Occurs when fluent text presents false or fabricated facts, citations, or URLs. Grounding and verification are essential safeguards.

Chapter 03

Chat Models, Human Feedback, and Tools

Big idea: A base language model completes text; a chat assistant is trained and structured to follow instructions, interact with roles, and cooperate with tools.

Alignment Pipeline (SFT → RLHF)

  • Supervised Fine-Tuning (SFT): Human-written examples teach assistant behavior.
  • Reward Model: Learns human preference scoring across candidate responses.
  • RLHF (PPO): Optimizes model responses to maximize reward without reward hacking.

Chapter 04

Designing Applications with Language Models

Big idea: The model produces text; the application turns a real-world problem into the right model input and turns the output into a useful result.

Application Pipeline Loop

User Goal $\rightarrow$ Context Retrieval $\rightarrow$ Prompt Assembly $\rightarrow$ Model Call $\rightarrow$ Validation $\rightarrow$ Action.

Tool Execution Patterns

Read-only tools (search/lookup) vs. Write-capable tools (create/edit). Write actions require strict validation and confirmation checks.

Chapter 05

Prompt Content & Retrieval-Augmented Generation (RAG)

Big idea: The quality of an LLM response depends on which information enters the prompt.

RAG System Architecture

  1. Indexing: Snippetizing text into manageable chunks and computing vector embeddings.
  2. Retrieval: Nearest-neighbor search via Cosine Similarity or Lexical/BM25 matching.
  3. Generation: Constructing grounded answers constrained strictly to retrieved context.
