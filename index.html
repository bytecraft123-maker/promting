Module 01

Introduction to Prompt Engineering

A language model produces a continuation of the information it receives. Prompt engineering is the practice of making that continuation useful, relevant, and reliable.

Historical Evolution

  • 1940s+: Statistical models & Markov approaches.
  • 2014: Seq2Seq architecture (Encoder-Decoder).
  • 2017: Transformer Architecture & Attention mechanism.
  • 2018+: Generative Pre-trained Transformers (GPT).

Operational Prompt Principles

1. Target Audience: Explicitly define who the output is for.
2. Scope & Structure: Define topic bounds and presentation order.
3. Constraints: Set clear limits on length, format, and terminology.
Module 02

Understanding How Language Models Work

Tokenization

Models operate on token IDs, not words. Punctuation & whitespace impact budget.

Temperature

Controls softmax output sharpness. Lower values = factual; Higher = creative.

Hallucination

Fluent but incorrect predictions. Requires strict grounding & verification.

Module 05

Context & Retrieval-Augmented Generation (RAG)

Retrieval Pipelines

Includes chunking documents with fixed window/stride, computing embeddings, and running Cosine Similarity search over vector indices (e.g. FAISS).

Grounded Generation

Constrains model answers strictly to retrieved context to eliminate hallucinations and enforce factual traceability.
